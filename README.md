# PB01 — Estrutura inicial da aplicação Web

Estrutura criada conforme o roteiro fornecido:
- páginas-base;
- componentes básicos;
- React Router;
- CSS global;
- estrutura de assets, hooks, services e utils.

## Instalação

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Git

Depois de colocar esta estrutura dentro do repositório do grupo:

```bash
git checkout -b feature/initial-structure
git add .
git commit -m "feat: create initial application structure"
git push -u origin feature/initial-structure
```
